# LOOKS — eshop (prototyp)

Klikací prototyp eshopu LOOKS Studio: kolekce 12 mikin, detail produktu, košík a pokladna.
Čistý HTML/CSS/JS, bez buildu a bez závislostí. Objednávky se nikam neodesílají.

## Spuštění lokálně
```
python3 -m http.server 8000
```
a otevři http://localhost:8000 (nebo jen dvojklik na `index.html`).

## Úpravy
- Produkty, ceny, doprava, platby: `js/products.js` (ceny jsou zatím ilustrační)
- Barvy a fonty: proměnné na začátku `css/style.css`
- Fotky: `img/` — zatím vyřezané z kolekční koláže, nahraď ostrými se stejnými názvy
